# Installation de l'application et lancement

## Pré-requis
- Installer **Git**
- Installer **Node.js / npm**
- Installer **Vite**


---

## Wink Web (front React + Vite)

- Cloner le dépôt :  
  `git clone <URL_DU_DEPOT_WINK_WEB> wink_web`
- Aller dans le dossier :  
  `cd wink_web`
- Installer les dépendances :  
  `npm install`
- Lancer l'app :  
  `npm run dev`

## Lien avec le backend ( Express.js )
    - Pour test les intéractions avec la base de données, il faudra voir cela dans le projet wink-back 
    - Ces intéractions sont faites à base de call sur l'api du backend donc il faut s'assurer que le backend soit bien lancé
